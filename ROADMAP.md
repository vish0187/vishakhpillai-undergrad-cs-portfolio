## Quality bar for featured projects

A mature featured project should aim to include:
- a clear problem and purpose
- transparent coursework origin where applicable
- independent engineering contributions
- clean source organization
- tests
- setup and usage instructions
- architecture/design explanation when useful
- a real demo for user-facing software
- limitations and future work
- measurable evidence when making performance claims
