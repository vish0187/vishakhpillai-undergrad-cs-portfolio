## Assignment

The exercise required a Java `Token` class containing:
- a private `String` storing the token value
- a constructor accepting a string
- `getValue()`
- `setValue()`
- an overridden `toString()` returning the stored value

My submitted work also included a no-argument constructor that initializes the value to an empty string.
