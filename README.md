## About

This portfolio follows my development as a computer science student across four undergraduate years.

Selected projects begin with concepts or assignments I genuinely completed in class. I then extend those ideas independently when there is a useful project worth building.

> **Learn it in class → understand it → build with it → improve it**

Coursework and independent extensions are kept separate so the origin of each project stays clear.

## What I care about

- **Authenticity** — projects stay traceable to work I actually did.
- **Depth over quantity** — related assignments can grow into one stronger project.
- **Usability** — mature projects should be easy for someone else to run or try.
- **Evidence** — tests, demos, architecture, benchmarks, and results are added when they genuinely exist.
- **Growth** — the portfolio should make my progression from freshman fundamentals to advanced work visible.
